# 🚀 Personal Portfolio Website

A modern, fully responsive personal portfolio website built to showcase my **skills, projects, education, experience, achievements, and professional journey** as a Computer Science professional.

## ✨ Features

- 🎨 Modern and clean UI
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- 🧭 Active navbar navigation
- 👩‍💻 About Me section
- 🛠️ Interactive Skills section with category filtering
- 💼 Experience section
- 🚀 Projects showcase
- 🎓 Education section
- 🏆 Achievements section
- 📄 Resume download
- 📩 Contact form
- 💬 Floating WhatsApp button
- 🔗 Social media integration
- ✨ Smooth scrolling and animations
- 💾 Theme preference saved using Local Storage

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap 5**
- **Bootstrap Icons**
- **Git & GitHub**
